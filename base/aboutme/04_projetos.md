# Projetos Desenvolvidos

## Nome do Projeto: App de Controle de Produção (Fita Adesiva)
**Ano:** 2023
**Tecnologias:** React Native, Node.js, Excel Integration.
**Link:** Não disponível (Projeto interno)
**Descrição:** Desenvolvimento de um aplicativo móvel para o registro de produção de fitas adesivas a cada hora. O app digitalizou um processo que antes exigia anotações manuais em papel e posterior transcrição.
**Meu papel:** Desenvolvimento Full Stack (Mobile e Backend).
**Desafio Superado:** Criei uma solução personalizada sem banco de dados convencional, onde o backend em Node.js salvava os registros diretamente em planilhas Excel para automação do controle administrativo. O sistema funcionou até a empresa migrar para um ERP profissional.

## Nome do Projeto: Plataforma Informativa - Evento Agro Defesa (ADAF)
**Ano:** 2025
**Tecnologias:** React.js, Node.js.
**Link:** Não disponível
**Descrição:** Aplicação web desenvolvida para o evento de Agro Defesa realizado no Centro de Convenções Vasco Vasques. O sistema foi criado para apresentar de forma interativa os tópicos abordados nas palestras, detalhando as responsabilidades e áreas de atuação da Agência de Defesa Agropecuária e Florestal (ADAF).
**Meu papel:** Desenvolvimento Full Stack (Frontend e Backend).
**Desafio Superado:** Traduzir informações regulatórias e técnicas da ADAF em uma interface intuitiva para o público do evento, garantindo que os participantes compreendessem visualmente o escopo de atuação do órgão.


## Nome do Projeto: Sistema de Pesquisa Eleitoral com Agente de Voz (IA)
**Ano:** 2024
**Tecnologias:** React.js, Node.js, Twilio, Integração de Voice AI API (Third-party), Data Visualization.
**Link:** [Link ou "Projeto Privado"]
**Descrição:** Plataforma avançada para automação de sondagens eleitorais o usuário dispara chamadas onde um Agente de IA conversacional entrevista os eleitores, seguindo um roteiro dinâmico para captar intenções de voto. O sistema permite o upload  contatos via planilhas (Excel/CSV).
**Meu papel:** Desenvolvimento Full Stack e Arquitetura de Integração.
**Desafio Superado:** Orquestração complexa entre telefonia (Twilio) e Inteligência Artificial. O grande desafio foi estruturar os dados da conversa em tempo real: o sistema traduz o diálogo da IA com o eleitor em dados quantitativos, alimentando instantaneamente um dashboard com gráficos comparativos dos candidatos.
